# 조건픽 표시 시제품 0.1.1

다나와 노트북 페이지에서 결과 표시 위치를 검증하기 위한 Chrome 확장 프로그램입니다.

## 들어 있는 동작

- 페이지 안 결과 영역, 페이지 위 오른쪽 패널, 별도 탭 전환
- 기본 표시 위치·예산·배송비 포함 여부·조합 체크의 브라우저 내 보관
- 표시 위치를 바꿔도 같은 샘플 결과 유지
- 페이지 안 영역 닫기 및 다나와 기본 화면 유지
- 표시 실패 시 기본 표시 설정을 바꾸지 않는 별도 탭 대안
- 원본 다나와 상품 상세 링크

오른쪽 패널은 Chrome 고유의 사이드 패널이 아니라 웹페이지 위에 열리는 패널입니다. 닫으면 원래 화면을 그대로 사용할 수 있습니다.

## 아직 연결하지 않은 동작

실제 사이트 옵션 담기, 조합 자동 검색, 모든 페이지 수집, 배송비·예산 판정은 다음 단계입니다.
조합 A·B는 표시 예시이며 현재 다나와 선택 옵션을 읽은 결과가 아닙니다.
'샘플 표시'는 이전 검증에서 확인한 두 상품 구성의 링크를 보여 줍니다. 실시간 판매 정보와 가격을 보증하거나 현재 입력한 예산에 맞는 상품을 검색하지 않습니다.
이 시제품은 표시 검증을 위해 한 개의 공통 작업 공간을 사용합니다. 여러 다나와 탭의 실제 검색을 독립적으로 처리하는 기능은 아직 없습니다.

## 직접 설치하고 확인하기

Chrome 109 이상에서 개발용으로 확인할 수 있습니다. 브라우저 고유 패널 API는 사용하지 않습니다.

1. ZIP을 받았다면 새 폴더에 압축을 풉니다. 소스 코드에서는 이 README와 manifest.json이 있는 extension 폴더를 사용합니다.
2. Chrome의 확장 프로그램 관리 화면(chrome://extensions)을 엽니다.
3. 사용자가 개발자 모드를 켜고 '압축해제된 확장 프로그램을 로드합니다'에서 해당 폴더를 선택합니다.
4. https://prod.danawa.com/list/?cate=112758 를 열거나, 이미 열려 있다면 새로고침합니다.
5. 오른쪽 아래 '조건픽 열기'를 누릅니다. 영역이 없으면 도구 모음의 조건픽 아이콘을 눌러 별도 탭 대안을 이용합니다.
6. '샘플 표시'를 누르고 배송비 설정·예산·조합 체크를 바꿉니다.
7. 표시 위치를 바꾸고 같은 값과 결과가 유지되는지 확인합니다.
8. 닫은 뒤 기존 다나와 필터와 상품 목록이 유지되는지 확인합니다.

표시하지 못해도 실제로 검색을 수행하지는 않습니다. 사이트 개편으로 목록 위치를 못 찾는 경우에는 안내와 별도 탭 보기를 제공합니다.

## 데이터와 권한

- 설정과 샘플은 chrome.storage.local에 보관하며 외부 서버로 전송하지 않습니다.
- storage: 설정과 표시 결과 보관
- activeTab: 사용자가 도구 모음 아이콘을 눌렀을 때 현재 다나와 탭 확인
- prod.danawa.com 접근: 노트북 목록에 조건픽 영역 추가 및 표시 위치 전환
- 콘텐츠 스크립트는 노트북 카테고리(cate=112758)에서만 실행합니다.
- 상품 링크는 HTTPS의 prod.danawa.com/info/ 주소와 숫자 상품 번호만 허용합니다.

사용자가 실제 Chrome에 확장을 추가하고 다나와에서 조건픽 영역이 열리는 것을 확인했습니다. 나머지 실제 Chrome 전환 동작은 아직 직접 검증하지 못했습니다. 자동 테스트는 DOM 환경과 Chrome API 대역으로 표시·복구·상태 유지·실패 처리를 검증합니다.

0.1.1에서는 표시 위치를 선택한 뒤 배송비 설정을 바꾸면 선택 위치가 기본값으로 되돌아가던 문제를 수정했습니다. 저장된 설정 형식은 유지합니다. 이미 확장을 불러온 브라우저는 확장 새로고침과 다나와 페이지 새로고침 후 변경 사항이 적용됩니다.

## 개발

저장소 루트에서 npm install --ignore-scripts 후 npm run check, npm test를 실행합니다.
npm run package는 outputs/condition-pick-display-prototype.zip을 생성합니다. 실행 시 외부 패키지를 사용하는 코드는 없으며 jsdom은 테스트에만 사용합니다.
