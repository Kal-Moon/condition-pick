# 조건픽 · ConditionPick

> 내 조건을 조합해, 원하는 상품을 찾다.

조건픽은 기존 가격 비교·쇼핑 사이트가 제공하는 상품과 옵션을 활용해, 사용자가 원하는 조건의 조합으로 상품을 찾고 여러 설정을 비교하도록 돕는 도구입니다. 노트북뿐 아니라 음식, 의류 등 다양한 상품군에 적용하는 것을 목표로 합니다.

## 해결하려는 문제

일반적인 개별 옵션 선택만으로는 사용자가 허용하는 조건 간 관계를 표현하기 어렵습니다.

예를 들어 예산 안에서 노트북을 찾을 때, CPU가 i5라면 특정 외장 GPU를 원하지만 i7이나 i9이라면 내장 그래픽도 허용할 수 있습니다. CPU와 GPU를 각각 여러 개 선택하면 원하지 않는 조합까지 결과에 포함될 수 있습니다.

조건픽은 사용자가 허용한 조합 중 하나를 만족하는 상품을 찾고, 어떤 조건으로 검색 결과에 포함되었는지 보여 줍니다.

## 확정된 제품 방향

- 기존 사이트가 제공하는 옵션을 조건의 재료로 사용한다. 자체 상품 카탈로그와 옵션 목록을 운영하는 것을 전제로 하지 않는다.
- 여러 속성을 묶어 조건 조합을 만든다. CPU·GPU 두 항목에 한정하지 않는다.
- 조합 안의 조건은 모두 만족해야 하고, 선택한 여러 조합 중에서는 하나 이상을 만족하면 된다.
- 조합을 여러 개 만들고 적용할 조합을 선택할 수 있다.
- 조합별 결과를 따로 비교하고, 선택한 조합들의 결과를 합쳐 검색한다. 같은 판매 구성의 상품이 여러 조합에 걸리면 한 번만 표시하고 만족한 조합들을 함께 표기한다.
- 예산·RAM·저장공간 등은 모든 조합에 공통으로 적용하거나 특정 조합에 넣을 수 있다.
- 상품군마다 속성은 달라도 조건을 조합하는 방식은 공통으로 사용한다.
- Jungle_REACT 팀 과제와 독립된 프로젝트다.

## 사용자 사례

아래 값은 사용자가 선택한 검색 조건의 예시이며 실제 출시 제품 목록이나 CPU 성능 순위를 뜻하지 않습니다.

공통 조건:

- 가격: 사용자가 정한 예산 이하
- RAM: 32GB 이상
- 저장공간: 512GB 또는 1TB

허용하는 조합:

1. CPU가 i5이고 GPU가 RTX 5050·5060·5070·5080·5090 또는 사용자가 선택한 해당 Ti 모델인 경우
2. CPU가 i7 또는 i9인 경우. GPU 종류는 제한하지 않아 내장 그래픽도 허용한다.

검색 의미:

```text
공통 조건 모두 만족
그리고
(
  (CPU가 i5 그리고 GPU가 선택 목록에 포함)
  또는
  (CPU가 i7 또는 i9)
)
```

CPU의 세대·정확한 모델과 GPU 모델은 별도 속성으로 다룬다. i5·i7·i9 명칭만으로 실제 성능을 단정하지 않는다.

## 첫 MVP 제안 — 검토 중

첫 지원 사이트는 다나와, 첫 검증 상품군은 노트북으로 확정했다. 전체 서비스의 대상 상품군을 노트북으로 한정하는 것은 아니다. 실제 옵션 접근·검색 방법은 검증 중이다.

1. 조건픽에서 예산과 배송비 기준 등 공통 조건을 정한다.
2. 다나와에서 원하는 옵션들을 선택하고 '조합 A로 담기'를 누른다.
3. 다나와 옵션을 바꿔 '조합 B로 담기' 등 여러 조합을 만든다.
4. 적용할 조합들을 선택하고 '선택한 조합 검색'을 누른다.
5. 조합별 결과를 비교하거나 선택한 조합의 통합 결과를 확인한다. 만족한 조합과 조건 설명도 우선 시도한 뒤 유용성을 검증한다.

기본 화면은 공통 조건, 여러 조합 카드, 조합별 결과, 선택 조합의 통합 결과로 구성한다. 공통 조건까지 다른 설정 묶음을 비교하는 추가 화면은 후속 제안으로 남기고, 우선 조합 A·B 자체의 비교와 선택 조합 통합 검색부터 검증한다.

사이트가 제공하는 옵션과 데이터로 표현 가능한 조건부터 지원한다. 아래는 필요한 조건 연산의 제안이며, 사이트가 제공하지 않는 사양을 임의로 채우지 않는다.

| 속성 종류 | 선택 방식 | 예시 |
| --- | --- | --- |
| 숫자 | 이상·이하·범위·정확한 값 | RAM 32GB 이상, 예산 이하 |
| 선택 목록 | 선택한 값 중 하나 | CPU i7 또는 i9 |
| 여부 | 필요·불필요·제한 없음 | 특정 기능 필요 |
| 용량 | 단위를 맞춘 정확한 값 목록 또는 범위 | 512GB 또는 1TB, 1TB 이상 |

'512GB 또는 1TB'와 '512GB 이상'은 다른 조건으로 취급한다. 옵션을 선택하지 않은 속성은 제한하지 않는다.

필수 사양이 없는 상품은 조건을 만족했다고 간주하지 않고, 확인이 필요한 후보로 구분한다. 가격·사양의 출처와 확인 시점도 표시한다.

## 확정된 사용·검색 규칙

### 조합 담기와 수정

- 다나와에서 선택한 옵션을 조합으로 담는다. 담아둔 조합은 이후 사이트 옵션을 바꿔도 유지한다.
- 기존 조합은 사용자가 명시적으로 수정할 때만 변경한다.
- 비교한 여러 조합 중 원하는 조합을 골라 통합 검색한다.

### 배송비와 예산

- 기본값은 배송비 포함이다. 사용자가 원하면 배송비 제외를 선택할 수 있다.
- 포함 모드에서는 상품 가격 + 배송비, 제외 모드에서는 상품 가격으로 정렬·비교하고 예산을 판정한다.
- 선택한 가격 기준은 모든 조합에 동일하게 적용한다.
- 현재 기준과 상품 가격·배송비를 구분해 표시한다.
- 포함 모드에서 배송비를 모르면 무료로 취급하지 않고 '배송비 확인 필요'로 표시한다. 해당 상품의 예산 충족 여부는 확인이 필요한 상태로 둔다.

### 검색 범위와 진행 상황

- 목표 검색 범위는 선택한 조합 각각에 해당하는 모든 결과 페이지다. 다나와에서 실제로 실행 가능한 범위는 검증해야 한다.
- 확인한 상품부터 점진적으로 표시하고, 조합별 확인 페이지와 진행 상태를 보여 준다.
- 현재 페이지나 일부 페이지만 확인한 결과는 '일부 결과'로 표시한다. 실패·중단 시에도 확인 범위를 유지한다.
- 선택한 모든 조합의 마지막 페이지까지 확인한 경우에만 통합 결과를 '검색 완료'로 표시한다.

### 재검색과 결과 상태

- 조건 변경만으로 자동 재검색하지 않는다. 편집 후 '선택한 조합 검색' 버튼으로 한 번에 실행한다.
- 조건을 바꿔도 기존 결과를 유지하고 '조건이 변경되었습니다. 다시 검색해 주세요'라고 표시한다.
- 기존 결과에는 검색 당시의 조건과 가격 기준을 연결한다. 새 조건의 결과처럼 표시하지 않는다.
- 새 검색의 결과는 해당 검색 조건으로 구분해 표시한다. 서로 다른 검색의 상품 목록을 섞지 않는다.

## 검증 기준 제안

- 사용자가 위 노트북 예시를 도움 없이 조건 카드로 표현할 수 있다.
- i5 + 허용 GPU는 포함하고, i5 + 허용하지 않은 GPU는 제외한다.
- i7/i9 + 내장 그래픽과 외장 그래픽 모두 GPU 제한이 없는 조합에서 허용한다.
- 예산·RAM·저장공간 공통 조건은 모든 조합에 적용된다.
- 선택하지 않은 조합은 검색에 적용되지 않는다. 선택한 조합이 없으면 검색 전에 선택을 요청한다.
- 다나와의 옵션 변경이 이미 담아둔 조합을 덮어쓰지 않는다.
- 배송비 포함·제외 변경에 따라 비교 금액과 예산 판정이 함께 바뀐다. 배송비 미확인 상품은 무료로 계산되지 않는다.
- 일부 조합이나 페이지만 확인한 상태를 전체 검색 완료로 표시하지 않는다.
- 조건을 수정하면 기존 결과가 이전 조건의 결과라는 표시가 나타난다. 검색 버튼을 누르기 전에는 재검색하지 않는다.
- 여러 설정을 바꿔도 각 설정의 조건이 서로 섞이지 않는다.
- 결과의 조합 설명이 이해와 비교에 도움이 되는지 검증한다.
- 음식·의류의 예시 속성으로도 같은 조건 구조를 표현할 수 있다.

## 후속 검토

- 다나와가 제공하는 옵션의 구조, 옵션·상품 정보 접근 및 검색 실행 가능성
- 사이트가 제공하는 단순 필터로 여러 조합을 실행하고 결과를 합치거나 비교할 수 있는 방법
- 공식 API·제휴 가능성, 이용 정책, 검색 범위와 페이지 누락 여부
- 조합별 비교와 설정별 비교의 화면 단위 및 표시 방식
- 가격 비교와 상품 간 호환성 검사의 구체적 범위
- 브라우저 확장 프로그램의 필요성과 역할
- 기술 스택, 저장 방식, 계정 기능

확인일: 2026-11-10. 아래는 공개 페이지의 텍스트를 확인한 결과이며, 브라우저에서 필터를 실제 적용하는 기능은 아직 검증하지 않았다.

- [다나와 이용약관](https://www.danawa.com/info/provision.html) 제24조에 지적재산권이 귀속된 정보의 사전 승낙 없는 영리 목적 이용 등에 관한 제한이 있다. 확장 프로그램의 구체적인 데이터 처리 방식에 대한 허용 여부를 이 확인만으로 결론 내리지 않는다.

첫 구현 방식은 사용자가 다나와에서 실행하는 브라우저 확장 프로그램을 우선 검토한다. 구현 전 다음 순서로 작은 동작 검증을 한다.

1. 실제 페이지에서 제공하는 옵션의 이름·값을 읽고, 해당 사이트의 선택과 연결한다.
2. 공통 조건 + 조합 A, 공통 조건 + 조합 B를 각각 실행하고 수동 검색 결과와 대조한다.
3. 선택한 조합의 결과를 합치되, RAM·SSD·OS 등 판매 구성이 다른 상품을 같은 상품으로 잘못 합치지 않는다.
4. 배송비·할인 적용 기준을 동일하게 유지하고 표시한다.
5. 페이지 이동과 추가 로딩 범위를 확인한다. 일부 페이지만 확인했으면 전체 검색 결과처럼 표시하지 않는다.

현재 단계는 기획과 실현 가능성 확인이며 구현은 시작하지 않았습니다. 다음 단계는 다나와의 실제 옵션 선택과 검색 갱신 동작을 확인하는 것입니다.
