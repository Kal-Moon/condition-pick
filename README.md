# 조건픽 · ConditionPick

> 내 조건을 조합해, 원하는 상품을 찾다.

조건픽은 기존 가격 비교·쇼핑 사이트가 제공하는 상품과 옵션을 활용해, 사용자가 원하는 조건의 조합으로 상품을 찾고 여러 설정을 비교하도록 돕는 도구입니다. 노트북뿐 아니라 음식, 의류 등 다양한 상품군에 적용하는 것을 목표로 합니다.

## 해결하려는 문제

일반적인 개별 옵션 선택만으로는 사용자가 허용하는 조건 간 관계를 표현하기 어렵습니다.

예를 들어 예산 안에서 노트북을 찾을 때, CPU가 i5라면 특정 외장 GPU를 원하지만 i7이나 i9이라면 내장 그래픽도 허용할 수 있습니다. CPU와 GPU를 각각 여러 개 선택하면 원하지 않는 조합까지 결과에 포함될 수 있습니다.

조건픽은 사용자가 허용한 조합 중 하나를 만족하는 상품을 찾고, 어떤 조건으로 검색 결과에 포함되었는지 보여 줍니다.

## 확정된 제품 방향

- 기존 사이트가 제공하는 옵션을 조건의 재료로 사용한다. 자체 상품 카탈로그와 옵션 목록을 운영하는 것을 전제로 하지 않는다.
- 여러 속성을 묶어 조건 조합을 만든다. CPU·GPU 두 항목에 한정하지 않는다.
- 조합 안의 조건은 모두 만족해야 하고, 선택한 여러 조합 중에서는 하나 이상을 만족하면 된다.
- 조합을 여러 개 만들고 적용할 조합을 선택할 수 있다.
- 서로 다른 조건 설정을 여러 개 만들어 비교할 수 있어야 한다. 비교 화면의 단위와 배치는 후속 설계에서 확인한다.
- 예산·RAM·저장공간 등은 모든 조합에 공통으로 적용하거나 특정 조합에 넣을 수 있다.
- 상품군마다 속성은 달라도 조건을 조합하는 방식은 공통으로 사용한다.
- Jungle_REACT 팀 과제와 독립된 프로젝트다.

## 사용자 사례

아래 값은 사용자가 선택한 검색 조건의 예시이며 실제 출시 제품 목록이나 CPU 성능 순위를 뜻하지 않습니다.

공통 조건:

- 가격: 사용자가 정한 예산 이하
- RAM: 32GB 이상
- 저장공간: 512GB 또는 1TB

허용하는 조합:

1. CPU가 i5이고 GPU가 RTX 5050·5060·5070·5080·5090 또는 사용자가 선택한 해당 Ti 모델인 경우
2. CPU가 i7 또는 i9인 경우. GPU 종류는 제한하지 않아 내장 그래픽도 허용한다.

검색 의미:

```text
공통 조건 모두 만족
그리고
(
  (CPU가 i5 그리고 GPU가 선택 목록에 포함)
  또는
  (CPU가 i7 또는 i9)
)
```

CPU의 세대·정확한 모델과 GPU 모델은 별도 속성으로 다룬다. i5·i7·i9 명칭만으로 실제 성능을 단정하지 않는다.

## 첫 MVP 제안 — 검토 중

첫 검증 사례는 기존 사이트의 노트북 검색으로 둔다. 전체 서비스의 대상 상품군을 노트북으로 한정하는 것은 아니다. 첫 지원 사이트와 실제 옵션 접근·검색 방법은 아직 정하지 않았다.

1. 지원 사이트의 상품군과 제공 옵션을 바탕으로 조건을 만든다.
2. 예산 등 공통 조건과 조합 카드들을 하나의 설정 안에서 편집한다.
3. 조합 카드를 여러 개 추가·수정·삭제하고, 적용할 카드들을 선택한다.
4. 조건 설정을 여러 개 만들고 선택해 비교한다.
5. 조건과 일치하는 상품을 확인한다. 만족한 조합과 조건 설명도 우선 시도한 뒤 유용성을 검증한다.

화면 구조 제안: 하나의 '설정'은 공통 조건과 여러 조합을 담는다. 예를 들어 설정 1 안에서 조합 A와 B를 함께 적용하고, 예산이나 RAM 조건을 바꾼 설정 2와 결과를 비교한다. 이 구분은 사용자 확인 전의 제안이며, 조합 A·B 자체의 결과 비교도 설계 시 함께 검토한다.

사이트가 제공하는 옵션과 데이터로 표현 가능한 조건부터 지원한다. 아래는 필요한 조건 연산의 제안이며, 사이트가 제공하지 않는 사양을 임의로 채우지 않는다.

| 속성 종류 | 선택 방식 | 예시 |
| --- | --- | --- |
| 숫자 | 이상·이하·범위·정확한 값 | RAM 32GB 이상, 예산 이하 |
| 선택 목록 | 선택한 값 중 하나 | CPU i7 또는 i9 |
| 여부 | 필요·불필요·제한 없음 | 특정 기능 필요 |
| 용량 | 단위를 맞춘 정확한 값 목록 또는 범위 | 512GB 또는 1TB, 1TB 이상 |

'512GB 또는 1TB'와 '512GB 이상'은 다른 조건으로 취급한다. 옵션을 선택하지 않은 속성은 제한하지 않는다.

필수 사양이 없는 상품은 조건을 만족했다고 간주하지 않고, 확인이 필요한 후보로 구분한다. 가격·사양의 출처와 확인 시점도 표시한다.

## 검증 기준 제안

- 사용자가 위 노트북 예시를 도움 없이 조건 카드로 표현할 수 있다.
- i5 + 허용 GPU는 포함하고, i5 + 허용하지 않은 GPU는 제외한다.
- i7/i9 + 내장 그래픽과 외장 그래픽 모두 GPU 제한이 없는 조합에서 허용한다.
- 예산·RAM·저장공간 공통 조건은 모든 조합에 적용된다.
- 선택하지 않은 조합은 검색에 적용되지 않는다. 선택한 조합이 없으면 검색 전에 선택을 요청한다.
- 여러 설정을 바꿔도 각 설정의 조건이 서로 섞이지 않는다.
- 결과의 조합 설명이 이해와 비교에 도움이 되는지 검증한다.
- 음식·의류의 예시 속성으로도 같은 조건 구조를 표현할 수 있다.

## 후속 검토

- 사이트가 제공하는 단순 필터로 여러 조합을 실행하고 결과를 합치거나 비교할 수 있는 방법

- 조합별 비교와 설정별 비교의 화면 단위 및 표시 방식
- 가격 비교와 상품 간 호환성 검사의 구체적 범위

- 기술 스택, 저장 방식, 계정 기능
