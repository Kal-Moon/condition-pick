# 조건픽 · ConditionPick

> 내 조건을 조합해, 원하는 상품을 찾다.

조건픽은 사용자가 원하는 조건과 조건의 조합을 직접 만들어 상품을 찾는 도구입니다. 노트북뿐 아니라 음식, 의류 등 다양한 상품군에 적용하는 것을 목표로 합니다.

## 해결하려는 문제

일반적인 개별 옵션 선택만으로는 사용자가 허용하는 조건 간 관계를 표현하기 어렵습니다.

예를 들어 예산 안에서 노트북을 찾을 때, CPU가 i5라면 특정 외장 GPU를 원하지만 i7이나 i9이라면 내장 그래픽도 허용할 수 있습니다. CPU와 GPU를 각각 여러 개 선택하면 원하지 않는 조합까지 결과에 포함될 수 있습니다.

조건픽은 사용자가 허용한 조합 중 하나를 만족하는 상품을 찾고, 어떤 조건으로 검색 결과에 포함되었는지 보여 줍니다.

## 확정된 제품 방향

- 여러 속성을 묶어 조건 조합을 만든다. CPU·GPU 두 항목에 한정하지 않는다.
- 조합 안의 조건은 모두 만족해야 하고, 여러 조합 중에서는 하나 이상을 만족하면 된다.
- 예산·RAM·저장공간 등은 모든 조합에 공통으로 적용하거나 특정 조합에 넣을 수 있다.
- 상품군마다 속성은 달라도 조건을 조합하는 방식은 공통으로 사용한다.
- Jungle_REACT 팀 과제와 독립된 프로젝트다.

## 사용자 사례

아래 값은 사용자가 선택한 검색 조건의 예시이며 실제 출시 제품 목록이나 CPU 성능 순위를 뜻하지 않습니다.

공통 조건:

- 가격: 사용자가 정한 예산 이하
- RAM: 32GB 이상
- 저장공간: 512GB 또는 1TB

허용하는 조합:

1. CPU가 i5이고 GPU가 RTX 5050·5060·5070·5080·5090 또는 사용자가 선택한 해당 Ti 모델인 경우
2. CPU가 i7 또는 i9인 경우. GPU 종류는 제한하지 않아 내장 그래픽도 허용한다.

검색 의미:

```text
공통 조건 모두 만족
그리고
(
  (CPU가 i5 그리고 GPU가 선택 목록에 포함)
  또는
  (CPU가 i7 또는 i9)
)
```

CPU의 세대·정확한 모델과 GPU 모델은 별도 속성으로 다룬다. i5·i7·i9 명칭만으로 실제 성능을 단정하지 않는다.

## 첫 MVP 제안 — 검토 중

첫 데이터 사례는 노트북으로 두고, 조건 조합 검색의 유용성을 먼저 검증한다. 전체 서비스의 대상 상품군을 노트북으로 한정하는 것은 아니다.

1. 상품군을 선택하고 예산 등 공통 조건을 입력한다.
2. 조건을 추가해 조합 카드를 만든다.
3. 조합 카드를 여러 개 추가하거나 수정·삭제한다.
4. 조건을 쉬운 문장으로 미리 확인한다.
5. 조건과 일치하는 상품을 확인하고 각 상품이 만족한 조합을 펼쳐 본다.

첫 버전의 조건 연산:

| 속성 종류 | 선택 방식 | 예시 |
| --- | --- | --- |
| 숫자 | 이상·이하·범위·정확한 값 | RAM 32GB 이상, 예산 이하 |
| 선택 목록 | 선택한 값 중 하나 | CPU i7 또는 i9 |
| 여부 | 필요·불필요·제한 없음 | 특정 기능 필요 |
| 용량 | 단위를 맞춘 정확한 값 목록 또는 범위 | 512GB 또는 1TB, 1TB 이상 |

'512GB 또는 1TB'와 '512GB 이상'은 다른 조건으로 취급한다. 옵션을 선택하지 않은 속성은 제한하지 않는다.

필수 사양이 없는 상품은 조건을 만족했다고 간주하지 않고, 확인이 필요한 후보로 구분한다. 가격·사양의 출처와 확인 시점도 표시한다.

## 검증 기준 제안

- 사용자가 위 노트북 예시를 도움 없이 조건 카드로 표현할 수 있다.
- i5 + 허용 GPU는 포함하고, i5 + 허용하지 않은 GPU는 제외한다.
- i7/i9 + 내장 그래픽과 외장 그래픽 모두 GPU 제한이 없는 조합에서 허용한다.
- 예산·RAM·저장공간 공통 조건은 모든 조합에 적용된다.
- 결과에서 어떤 조합을 만족했는지 사용자가 설명할 수 있다.
- 음식·의류의 예시 속성으로도 같은 조건 구조를 표현할 수 있다.
